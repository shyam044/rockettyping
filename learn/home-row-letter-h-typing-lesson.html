🖐️ Lesson: Type the Letter H

H is typed with your right index finger. Start with your finger resting on J,then move slightly to the left to press H. Return to the home-row position after each keystroke.

How to Type the Letter H Correctly

The letter H is typed using your right index finger. From the normal home-row position,your index finger rests on J. To type H,move that finger slightly to the left,press the key,and then return your hand to the home row.

This lesson uses four short drills — a single tap,double taps,triple taps,and a building rhythm — to help your right index finger learn the correct movement for H without looking down at the keyboard.

Which finger types the letter H?

Your right index finger. Begin with your index finger positioned on J,move slightly left to H,then return to the home-row position.

Where is the H key on the keyboard?

The H key is on the home row,between G and J. It is normally reached with the right index finger.
