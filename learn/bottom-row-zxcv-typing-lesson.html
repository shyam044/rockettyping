🖐️ Type Z X C V

Z,X,C and V are bottom-row keys. Use your left hand and the correct fingers to reach each key while keeping your hand anchored on the home row. These 4 exercises build the accuracy and muscle memory you need to type Z X C V confidently.

How to Type Z X C V Correctly

The letters Z, X, C and V are located on the bottom row of a standard QWERTY keyboard. Z is typed with the left pinky, X with the left ring finger, C with the left middle finger, and V with the left index finger.

This lesson uses four progressive drills. Start by practicing individual bottom-row movements, then move to two-letter combinations, three-letter patterns, and longer Z-X-C-V sequences to develop accuracy and muscle memory.

Which fingers type Z, X, C and V?

Z is typed with the left pinky, X with the left ring finger, C with the left middle finger, and V with the left index finger.

Are Z, X, C and V home-row keys?

No. Z, X, C and V are bottom-row keys. Your left-hand fingers reach downward from the home-row keys A, S, D and F.
