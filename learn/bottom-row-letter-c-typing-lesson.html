🖐️ Type the Letter C

C is typed with your left middle finger. Reach down from the D key to press C, then return your finger to its home-row position. These 4 exercises build the muscle memory you need to type C accurately without looking at the keyboard.

How to Type the Letter C Correctly

The letter C is a bottom-row key typed with your left middle finger. From the home row, your middle finger moves downward from D to C and then returns to D.

This lesson uses four short drills that gradually build your C typing skills. Start with individual taps, then practice repeated movements and increasingly complex patterns to develop accuracy and muscle memory.

Which finger types the letter C?

Your left middle finger. Start with your middle finger resting on D, move it downward to C, press the key, and return to the home row.

Is C a home-row key?

No. C is on the bottom row of a QWERTY keyboard. Your left middle finger reaches downward from D to type it.
