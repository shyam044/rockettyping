⌨️ Type QWERTYUIOP

QWERTYUIOP is the complete top row of a standard QWERTY keyboard. Practice reaching each key with the correct finger while keeping your hands anchored on the home row. These 4 exercises build the accuracy and muscle memory needed to type the top row confidently.

How to Type QWERTYUIOP Correctly

The letters Q, W, E, R, T, Y, U, I, O and P make up the top letter row of a standard QWERTY keyboard. Touch typing requires you to use the correct finger for each key while keeping your hands positioned over the home row.

This lesson uses four progressive exercises. You will begin with short words containing the top-row letters, then move through longer words and finally practice complete words that combine multiple top-row movements.

What is the QWERTY top row?

The QWERTY top row is the row containing the letters Q, W, E, R, T, Y, U, I, O and P. These keys are reached from the home row during touch typing.

Which fingers type the QWERTY top row?

Q, W, E and R are typed with the left pinky, ring, middle and index fingers. T is typed with the left index finger. Y, U, I and O are typed with the right index, index, middle and ring fingers, while P is typed with the right pinky finger.
