#11 Print N Numbers

Easy ⏱ 1 sec 💾 256 MB 🏷 Loops

Problem Statement

You are given an integer n. Print all the numbers from 1 up to and including n, separated by a single space, on one line.

Input Format

A single integer n.

Output Format

Print the numbers 1 through n, separated by single spaces, on one line.

Constraints

• 1 ≤ n ≤ 100

Sample Input

5

Sample Output

1 2 3 4 5

Explanation

For n = 5, the numbers 1 through 5 are printed in order, each separated by a space.
Use range(1, n + 1) to generate the numbers, then join them with spaces.

Print N Numbers in Java — 1 solution

StringBuilder loop

import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            if (i > 1) sb.append(" ");
            sb.append(i);
        }
        System.out.println(sb.toString());
    }
}

  3. Loops from 1 to n, adding a space before every number except the first.

Print N Numbers in Rust — 1 solution

Range + join

use std::io::{self, Read};
fn main() {
    let mut text = String::new();
    io::stdin().read_to_string(&mut text).unwrap();
    let n: i32 = text.trim().parse().unwrap();
    let nums: Vec<String> = (1..=n).map(|i| i.to_string()).collect();
    println!("{}", nums.join(" "));
}
  1. Reads all of standard input into a String.

  3. Builds the numbers 1 through n as strings using a range and map.
  4. Joins them with spaces and prints the result.

Frequently Asked Questions

How do I print numbers from 1 to n in Python?

Use range(1, n + 1) inside a loop, or build a list and join it with spaces: " ".join(str(x) for x in range(1, n + 1)).

What does range(1, n + 1) do in Python?

range(1, n + 1) generates numbers starting at 1 and stopping just before n + 1 — so it includes n itself, since range's upper bound is exclusive.

Why use join() instead of printing in a loop?

print() inside a loop adds a newline after each number by default. Building a list and joining it with " " produces all the numbers on one line with single spaces between them in one call.
