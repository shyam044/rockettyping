Problem Statement

You are given a list of integers on one line, separated by spaces. Increment the second element of the list (index 1) by 1, then print the modified list.

Input Format

A single line of space-separated integers, with at least 2 numbers.

Output Format

Print the modified list in standard list format, e.g. [1, 3, 3].

Constraints

• 2 ≤ number of elements ≤ 20

Sample Input

1 2 3

Sample Output

[1, 3, 3]

Explanation

The list is [1, 2, 3]. Its second element (index 1) is 2, so incrementing it by 1 gives [1, 3, 3].
Read the line, split it, convert each piece to an integer, then update arr[1] before printing.

    }

Increment Second List Element in Go — 1 solution

strconv.Atoi loop + Join

package main
import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)
func main() {
    reader := bufio.NewReader(os.Stdin)
    line, _ := reader.ReadString('\n')
    tokens := strings.Fields(line)
    arr := make([]int, len(tokens))
    for i, t := range tokens {
        arr[i], _ = strconv.Atoi(t)
    }
    arr[1]++
    parts := make([]string, len(arr))
    for i, v := range arr {
        parts[i] = strconv.Itoa(v)
    }
    fmt.Println("[" + strings.Join(parts, ", ") + "]")
}
  1. Reads the line and splits it into whitespace-separated tokens.

Frequently Asked Questions

Why is the second element at index 1, not index 2?

Programming languages almost universally use 0-based indexing — the first element is at index 0, so the second element is at index 1.

How do I read a line of space-separated numbers into a list in Python?

Split the line on spaces to get a list of strings, then convert each one with int(): [int(p) for p in input().split(" ")] does both in one line.

How do I print a list in Python's [1, 2, 3] format in other languages?

Build the comma-and-space-separated values yourself and wrap them in square brackets — e.g. "[" + ", ".join(str(x) for x in arr) + "]" — since most other languages don't print arrays that way by default.
