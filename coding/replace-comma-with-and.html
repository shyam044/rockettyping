#15 Replace Comma With 'and'

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a string containing two names separated by a comma (,), with no space around it — for example Tom,Jerry. Replace the comma with the word and (surrounded by single spaces) and print the result.

Input Format

A single string in the form name1,name2.

Output Format

Print the two names joined by and instead of the comma.

Constraints

• Each name contains only letters.
• The string contains exactly one comma.

Sample Input

Tom,Jerry

Sample Output

Tom and Jerry

Explanation

The comma between "Tom" and "Jerry" is replaced with the word "and", surrounded by spaces, giving "Tom and Jerry".
A single call to .replace(",", " and ") does the whole job.

About this problem: Replace Comma With 'and'

Swapping one piece of text for another inside a string — here, turning a bare comma into the word "and" — is the simplest possible introduction to string replacement, a tool you'll reach for constantly.

Python's single .replace(",", " and ") call handles it directly; other languages offer an equivalent replace method, or you can split the string at the comma and join the two halves back together with "and" in between. Solutions in all 13 languages are shown below, plus three Python variations.

Frequently Asked Questions

How do you replace one character with a word in Python?

Use .replace(old, new): s.replace(",", " and ") replaces every comma in s with the text " and ".

Does .replace() change the original string?

No — Python strings are immutable, so .replace() returns a new string. You need to store or print the result; the original string is unchanged.

What if the string has more than one comma?

s.replace(",", " and ") replaces every comma it finds. For this problem the input always has exactly one, so that's not an issue here.
