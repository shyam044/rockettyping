#2 Basic Arithmetic Operations

Easy ⏱ 1 sec 💾 256 MB 🏷 Math

Problem Statement

You are given two integers. Perform the following six arithmetic operations on them and print each result on a separate line, in the exact order listed:

1. Addition — the sum of the two numbers
2. Subtraction — the first number minus the second
3. Multiplication — the product of the two numbers
4. Division — the first number divided by the second (integer division — discard any remainder)
5. Modulo — the remainder when the first number is divided by the second
6. Power — the result of raising the first number to the power of the second

Input Format

Two integers a and b are given on two separate lines.

Output Format

Print exactly six lines, one result per operation, in the order:
a + b a - b a * b a / b (integer division) a % b a ^ b

Constraints

• 1 ≤ a, b ≤ 100
• b ≠ 0 (division by zero will not be tested)
• For the Power operation, the result fits within a standard integer.

Sample Input

10 3

Sample Output

13 7 30 3 1 1000

Explanation

With a = 10 and b = 3:
• 10 + 3 = 13
• 10 − 3 = 7
• 10 × 3 = 30
• 10 ÷ 3 = 3 (integer division; remainder is dropped)
• 10 mod 3 = 1 (10 = 3×3 + 1)
• 10³ = 1000
In Python, integer division uses `//` and power uses `**`.

About this problem: Basic Arithmetic Operations

This exercise covers the six core arithmetic operations in one program: addition, subtraction, multiplication, integer division, remainder (modulo) and power. You read two integers, then print each result on its own line in the required order.

It is a compact way to compare how languages handle operators — for example Python's // and ** against Java's Math.pow or C's pow(). Reference solutions are provided in all 13 languages.

Frequently asked questions

How do you do integer division in Python, Java and C++?

Python uses the // operator. In Java, C, C++, Go, C#, Kotlin and Swift, dividing two integers with / already drops the fraction. JavaScript has no integer type, so Math.floor(a / b) is used. For positive numbers these all give the same result.

How do you calculate a power in different languages?

Python, Ruby, JavaScript, TypeScript and PHP have the ** operator. Java uses Math.pow, C and C++ use pow(), Go uses math.Pow, C# uses Math.Pow and Rust integers have a .pow() method.

Why do some solutions print the power with %.0f?

100 to the power of 10 is 100000000000000000000, which does not fit in a 64-bit integer. Languages that compute powers as floating-point numbers print it in full when formatted with no decimals, Rust uses a 128-bit integer, and Python and Ruby integers grow automatically.
