#17 Format Two Words

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given two words separated by a single space, on one line. Convert the first word to uppercase and the second word to lowercase, then print them separated by a space.

Input Format

A single line containing two words separated by a space.

Output Format

Print the uppercased first word and the lowercased second word, separated by a single space.

Constraints

• Each word contains 1 to 30 letters.

Sample Input

Hello World

Sample Output

HELLO world

Explanation

"Hello" becomes "HELLO" (uppercase) and "World" becomes "world" (lowercase), printed with a space between them.
Split the line on the space to get the two words, then apply .upper() and .lower().

About this problem: Format Two Words

Reading two words from one line and formatting each one differently — uppercase the first, lowercase the second — combines two everyday skills: splitting a line into tokens, and changing letter case.

Python splits on the space, then applies .upper() and .lower() to each half (optionally with tuple unpacking or an f-string); every other language offers the same pair of case-conversion methods. Solutions in all 13 languages are shown below, plus three Python variations.

cin >> + toupper/tolower

#include <iostream>
#include <string>
#include <cctype>
using namespace std;
int main() {
    string a, b;
    cin >> a >> b;
    for (char &c : a) c = toupper((unsigned char)c);
    for (char &c : b) c = tolower((unsigned char)c);
    cout << a << " " << b << endl;
    return 0;
}
  1. Reads the two words directly with cin >>.
  2. Converts every character of the first word to uppercase.
  3. Converts every character of the second word to lowercase.
  4. Prints both words with a space between them.

strings.Split + ToUpper/ToLower

package main
import (
    "bufio"
    "fmt"
    "os"
    "strings"
)
func main() {
    reader := bufio.NewReader(os.Stdin)
    s, _ := reader.ReadString('\n')
    s = strings.TrimSpace(s)
    parts := strings.Split(s, " ")
    fmt.Println(strings.ToUpper(parts[0]) + " " + strings.ToLower(parts[1]))
}

Format Two Words in Rust — 1 solution

split_whitespace()

use std::io::{self, Read};
fn main() {
    let mut text = String::new();
    io::stdin().read_to_string(&mut text).unwrap();
    let s = text.trim();
    let mut parts = s.split_whitespace();
    let a = parts.next().unwrap();
    let b = parts.next().unwrap();
    println!("{} {}", a.to_uppercase(), b.to_lowercase());
}

Frequently Asked Questions

How do you split a line into two words in Python?

Call s.split(" ") to split on the space, giving a list of two strings, or unpack directly with a, b = s.split(" ").

What's the difference between .upper() and .capitalize()?

.upper() makes every character uppercase. .capitalize() only uppercases the first character and lowercases the rest. This problem needs the whole word uppercased, so .upper() is correct.

Can I do this in one line with an f-string?

Yes: print(f"{a.upper()} {b.lower()}") formats both converted words into one string in a single statement.
