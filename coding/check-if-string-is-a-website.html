#16 Check If Input Is a Website

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a string. Consider it a website if it starts with http (this also covers https) and ends with .com. Print Website if both conditions hold, otherwise print Not a Website.

Input Format

A single string s.

Output Format

Print exactly one line: either Website or Not a Website.

Constraints

• 1 ≤ length of s ≤ 100

Sample Input

https://www.google.com

Sample Output

Website

Explanation

The string starts with "http" and ends with ".com", so both conditions are satisfied and it prints "Website".
Combine .startswith("http") and .endswith(".com") with and.

Manual prefix/suffix check

#include <iostream>
#include <string>
using namespace std;
bool startsWith(const string &s, const string &p) {
    return s.size() >= p.size() && s.compare(0, p.size(), p) == 0;
}
bool endsWith(const string &s, const string &p) {
    return s.size() >= p.size() && s.compare(s.size() - p.size(), p.size(), p) == 0;
}
int main() {
    string s;
    getline(cin, s);
    bool result = startsWith(s, "http") && endsWith(s, ".com");
    cout << (result ? "Website" : "Not a Website") << endl;
    return 0;
}
  1. Defines a helper to check whether a string starts with a given prefix.
  2. Defines a helper to check whether a string ends with a given suffix.
  3. Reads the input line.
  4. Uses both helpers together and prints the result.

strncmp() + strcmp()

#include <stdio.h>
#include <string.h>
int main() {
    char s[105];
    fgets(s, sizeof(s), stdin);
    s[strcspn(s, "\n")] = '\0';
    int len = strlen(s);
    int startsHttp = strncmp(s, "http", 4) == 0;
    int endsCom = len >= 4 && strcmp(s + len - 4, ".com") == 0;
    printf("%s\n", (startsHttp && endsCom) ? "Website" : "Not a Website");
    return 0;
}
  1. Reads a line and strips the trailing newline.

Check If Input Is a Website in Go — 1 solution

strings.HasPrefix/HasSuffix

package main
import (
    "bufio"
    "fmt"
    "os"
    "strings"
)
func main() {
    reader := bufio.NewReader(os.Stdin)
    s, _ := reader.ReadString('\n')
    s = strings.TrimSpace(s)
    result := strings.HasPrefix(s, "http") && strings.HasSuffix(s, ".com")
    if result {
        fmt.Println("Website")
    } else {
        fmt.Println("Not a Website")
    }
}
  1. Reads a line and trims whitespace.
  2. Checks the prefix and suffix with strings.HasPrefix/HasSuffix.
  3. Prints Website or Not a Website based on the result.

Frequently Asked Questions

How do you check the start and end of a string in Python?

Use s.startswith("http") to check the beginning and s.endswith(".com") to check the end, combined with and so both conditions must be true.

Why doesn't "ftp://example.com" count as a website here?

It doesn't start with the literal text "http" — ftp:// starts with f, not h — so startswith("http") returns False even though it still ends in .com.

Does this also match https:// addresses?

Yes — "https" starts with "http" as a substring, so s.startswith("http") is True for both http:// and https:// URLs.
