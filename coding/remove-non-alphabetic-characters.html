#14 Remove Non-Alphabetic Characters

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a string that may contain letters, digits, spaces, and punctuation. Remove every character that is not an alphabetic letter (a-z, A-Z), and print the remaining letters joined together.

Input Format

A single string s.

Output Format

Print only the alphabetic characters of s, in their original order, with nothing else in between.

Constraints

• 1 ≤ length of s ≤ 100

Sample Input

Hello123 World!

Sample Output

HelloWorld

Explanation

Every digit, space, and the exclamation mark are removed, leaving only "Hello" and "World" joined together as "HelloWorld".
Loop over each character and keep it only if it appears in string.ascii_letters.

Character.isLetter loop

import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetter(c)) sb.append(c);
        }
        System.out.println(sb.toString());
    }
}

Remove Non-Alphabetic Characters in Go — 1 solution

unicode.IsLetter loop

package main
import (
    "bufio"
    "fmt"
    "os"
    "strings"
    "unicode"
)
func main() {
    reader := bufio.NewReader(os.Stdin)
    s, _ := reader.ReadString('\n')
    s = strings.TrimRight(s, "\r\n")
    result := ""
    for _, c := range s {
        if unicode.IsLetter(c) {
            result += string(c)
        }
    }
    fmt.Println(result)
}
  1. Reads a line and trims the trailing newline.
  2. Loops over every rune, keeping only letters via unicode.IsLetter.
  3. Prints the filtered result.

Remove Non-Alphabetic Characters in Rust — 1 solution

filter + is_ascii_alphabetic

use std::io::{self, Read};
fn main() {
    let mut text = String::new();
    io::stdin().read_to_string(&mut text).unwrap();
    let s = text.trim_end_matches('\n');
    let result: String = s.chars().filter(|c| c.is_ascii_alphabetic()).collect();
    println!("{}", result);
}
  1. Reads all of standard input.

Frequently Asked Questions

How do I keep only letters from a string in Python?

Loop over the string and keep each character only if it's in string.ascii_letters, or use a generator expression: "".join(ch for ch in s if ch in string.ascii_letters).

What is string.ascii_letters in Python?

It's a constant from the string module containing every lowercase and uppercase English letter: "abc...xyzABC...XYZ".

Can I use a regular expression instead?

Yes — re.sub("[^a-zA-Z]", "", s) removes everything that isn't an English letter in one call, which is what the JavaScript/TypeScript/Ruby solutions below use.
