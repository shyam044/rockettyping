#18 ASCII Value And Character Conversion

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a single character and an integer. Print the ASCII value of the given character, then print the character corresponding to the given integer's ASCII value.

Input Format

• First line: a single character c
• Second line: an integer n

Output Format

Print two lines:
1. The ASCII value of c
2. The character whose ASCII value is n

Constraints

• c is a single printable character.
• 0 ≤ n ≤ 127

Sample Input

A 98

Sample Output

65 b

Explanation

The ASCII value of "A" is 65, and the character with ASCII value 98 is "b".
ord(c) gives a character's ASCII value; chr(n) gives the character for a given ASCII value.

About this problem: ASCII Value And Character Conversion

Every character a computer stores is really just a number under the hood (its ASCII/Unicode code point) — converting between a character and that number is a fundamental skill for anything involving character-level logic.

Python's ord() goes character → number, and chr() goes number → character; every other language has a direct equivalent (casting a char to int in Java/C++/C#, charCodeAt/fromCharCode in JavaScript). Solutions in all 13 languages are shown below, plus three Python variations.

ASCII Value And Character Conversion in Rust — 1 solution

as u32 / char::from_u32

use std::io::{self, Read};
fn main() {
    let mut text = String::new();
    io::stdin().read_to_string(&mut text).unwrap();
    let mut it = text.split_whitespace();
    let c = it.next().unwrap().chars().next().unwrap();
    let n: u32 = it.next().unwrap().parse().unwrap();
    println!("{}", c as u32);
    println!("{}", char::from_u32(n).unwrap());
}

  3. Takes the first character of the first token.
  4. Parses the second token as a u32.
  5. Prints the character's numeric value, then the character for that value.

Frequently Asked Questions

What does ord() do in Python?

ord(c) takes a single character and returns its ASCII (Unicode) code point as an integer — ord("A") is 65.

What does chr() do in Python?

chr(n) is the opposite of ord(): it takes an integer code point and returns the character it represents — chr(98) is "b".

How do other languages do this?

Most languages let you cast a character straight to an integer and back (int c, char n in C/C++/Java/C#), or provide helpers like JavaScript's charCodeAt()/fromCharCode().
