#13 Check If Input Is a Digit

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a string. Check whether it consists entirely of digit characters (0-9). Print Digit if it does, and Not a Digit otherwise.

Input Format

A single string s.

Output Format

Print exactly one line: either Digit or Not a Digit.

Constraints

• 1 ≤ length of s ≤ 50

Sample Input

12345

Sample Output

Digit

Explanation

"12345" is made up only of digit characters, so it prints "Digit".
Python strings have a built-in .isdigit() method that checks exactly this.

About this problem: Check If Input Is a Digit

Before you can safely convert user input into a number, you often need to check whether it's actually numeric in the first place — this is one of the most common validation checks in real programs.

Python has a built-in .isdigit() method for exactly this; most other languages check each character individually with something like Character.isDigit or isdigit(). Solutions in all 13 languages are shown below, plus three Python variations.

Character.isDigit loop

import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().trim();
        boolean isDigit = true;
        for (char c : s.toCharArray()) {
            if (!Character.isDigit(c)) isDigit = false;
        }
        System.out.println(isDigit ? "Digit" : "Not a Digit");
    }
}

Check If Input Is a Digit in Go — 1 solution

unicode.IsDigit loop

package main
import (
    "bufio"
    "fmt"
    "os"
    "strings"
    "unicode"
)
func main() {
    reader := bufio.NewReader(os.Stdin)
    s, _ := reader.ReadString('\n')
    s = strings.TrimSpace(s)
    isDigit := true
    for _, c := range s {
        if !unicode.IsDigit(c) {
            isDigit = false
        }
    }
    if isDigit {
        fmt.Println("Digit")
    } else {
        fmt.Println("Not a Digit")
    }
}
  1. Reads a line and trims whitespace.
  2. Assumes it's all digits until proven otherwise.
  3. Checks every rune with unicode.IsDigit.
  4. Prints Digit or Not a Digit based on the result.

is_ascii_digit()

use std::io::{self, Read};
fn main() {
    let mut text = String::new();
    io::stdin().read_to_string(&mut text).unwrap();
    let s = text.trim();
    let is_digit = !s.is_empty() && s.chars().all(|c| c.is_ascii_digit());
    println!("{}", if is_digit { "Digit" } else { "Not a Digit" });
}

Frequently Asked Questions

How do you check if a string is all digits in Python?

Call s.isdigit() — it returns True only if every character in the string is a digit 0-9 and the string isn't empty.

Does isdigit() work on negative numbers like "-5"?

No — the minus sign isn't a digit character, so "-5".isdigit() returns False. isdigit() only recognizes 0-9.

What's a quick way to check this without isdigit()?

Loop over every character and check it against the set "0123456789", or try converting the string with int() inside a try/except and see if it succeeds.
