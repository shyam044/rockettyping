#12 Alternate Letters From Second Character

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a string. Starting from the second character (index 1), print every alternate letter of the string — that is, the characters at index 1, 3, 5, 7, and so on.

Input Format

A single string s.

Output Format

Print the alternate characters, starting from index 1, joined together with no separator.

Constraints

• 1 ≤ length of s ≤ 100

Sample Input

Rocket

Sample Output

okt

Explanation

For "Rocket": R(0) o(1) c(2) k(3) e(4) t(5). Taking every alternate character starting at index 1 gives o, k, t → "okt".
A slice like s[1::2] steps through the string two characters at a time, starting at index 1.

About this problem: Alternate Letters From Second Character

String indexing and slicing come up constantly in real code — picking out every other character is a small, concrete way to practice stepping through a string by index instead of just reading it left to right.

Python's slice syntax s[1::2] does the whole job in one expression; most other languages step through the string with a loop and an index that increases by 2 each time. Solutions in all 13 languages are shown below, plus three Python variations.

Alternate Letters From Second Character in Rust — 1 solution

chars().skip().step_by()

use std::io::{self, Read};
fn main() {
    let mut text = String::new();
    io::stdin().read_to_string(&mut text).unwrap();
    let s = text.trim();
    let chars: Vec<char> = s.chars().collect();
    let result: String = chars.iter().skip(1).step_by(2).collect();
    println!("{}", result);
}

Frequently Asked Questions

What does s[1::2] mean in Python?

It's a slice: start at index 1, go to the end (no stop given), and take every 2nd character (step 2) — exactly the odd-indexed characters of the string.

How do you loop over every other character in a string?

Start a loop at index 1 and increase the index by 2 each iteration, stopping once you've passed the end of the string: for i in range(1, len(s), 2).

What happens for a 1-character string like "A"?

There is no index 1, so nothing is selected and the result is an empty string.
