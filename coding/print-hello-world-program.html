Print Hello World Program in Python — 26 solutions

print() — single quotes

print('Hello World')
  1. Prints the text Hello World to the screen.

print() — double quotes

print("Hello World")
  1. Prints the text Hello World, using double quotes instead of single quotes.

Triple single quotes

print('''Hello World''')
  1. Prints Hello World using a triple-quoted string — handy when text itself contains quote characters.

Triple double quotes

print("""Hello World""")
  1. Same idea, but with triple double quotes instead of triple single quotes.

Implicit string concatenation

print("Hello " "World")
  1. Two string literals written next to each other are automatically joined into one, so this prints Hello World.

+ operator concatenation

print("Hello " + "World")
  1. Explicitly joins the two strings with the + operator before printing.

Comma-separated arguments

print("Hello", "World")
  1. print() automatically puts a single space between comma-separated arguments, so this prints Hello World.

f-string literal

print(f"Hello World")
  1. An f-string with no {placeholders} — it behaves just like a normal string here.

f-string with variables

a, b = "Hello", "World"
print(f"{a} {b}")
  1. Assigns Hello to a and World to b in one line.
  2. Uses an f-string to insert a and b into the printed text, separated by a space.

.format() — positional

print("{} {}".format("Hello", "World"))
  1. Uses .format() to drop the two arguments into the {} placeholders, in order.

.format() — indexed

print("{0} {1}".format("Hello", "World"))
  1. Same as .format(), but the placeholders explicitly name which argument index goes where.

.format() — keyword

print("{h} {w}".format(h="Hello", w="World"))
  1. The placeholders are named h and w, filled in by matching keyword arguments.

% string formatting

print("%s %s" % ("Hello", "World"))
  1. The older C-style % operator substitutes each %s with a value from the tuple, in order.

" ".join() on a list

print(" ".join(["Hello", "World"]))
  1. Joins the list ['Hello', 'World'] into one string, placing a single space between each item.

" ".join() on characters

print("".join(['H', 'e', 'l', 'l', 'o', ' ', 'W', 'o', 'r', 'l', 'd']))
  1. Joins a list of individual characters back into one string with no separator between them.

print(*list) unpacking

print(*["Hello", "World"])
  1. The * unpacks the list into two separate arguments, and print() puts a space between them by default.

Generator expression + join

print("".join(char for char in "Hello World"))
  1. Iterates over every character of the string and joins them back together, unchanged, one by one.

sys.stdout.write()

import sys
sys.stdout.write("Hello World\n")
  1. Imports the sys module, which gives lower-level access to standard output.
  2. Writes the text directly to standard output, including an explicit newline character.

Hex escape sequences

print("\x48\x65\x6c\x6c\x6f\x20\x57\x6f\x72\x6c\x64")
  1. Each \xNN is the hexadecimal code for one character — together they spell out Hello World.

Unicode escape sequences

print("\u0048\u0065\u006c\u006c\u006f\u0020\u0057\u006f\u0072\u006c\u0064")
  1. Same idea as hex escapes, but using 4-digit Unicode code points for each character.

chr() from ASCII codes

print("".join(chr(x) for x in [72, 101, 108, 108, 111, 32, 87, 111, 114, 108, 100]))
  1. Converts each ASCII code number to its character with chr(), then joins them into one string.

chr() from hex codes

print("".join(chr(int(x, 16)) for x in ['48', '65', '6c', '6c', '6f', '20', '57', '6f', '72', '6c', '64']))
  1. Parses each hex string as a base-16 number, converts it to a character, and joins the results.

Reversed-string slice

print("dlroW olleH"[::-1])
  1. Starts from the reversed text and uses a [::-1] slice to reverse it back to Hello World.

Base64 decode

import base64
print(base64.b64decode("SGVsbG8gV29ybGQ=").decode())
  1. Imports the base64 module for decoding Base64-encoded text.
  2. Decodes the Base64 string into bytes, then .decode() turns those bytes into the text Hello World and prints it.

eval()

eval('print("Hello World")')
  1. Treats the string as Python code and executes it, which runs the print() statement inside.

exec()

exec('print("Hello World")')
  1. Similar to eval(), but exec() runs a string as a full statement rather than an expression.

Frequently asked questions

How do you print Hello World in Python, Java and C++?

Python: print("Hello World"). Java: System.out.println("Hello World"); inside a main method of a class. C++: cout << "Hello World" << endl; after including <iostream>.

Which language needs the least code for Hello World?

Python, Ruby, JavaScript and Swift need just one line. Java, C#, C, C++, Go, Rust and Kotlin need a main function (Java and C# also a class), and PHP needs the <?php opening tag. All of them print the same text.

Why must the output match exactly?

Test cases compare your output with the expected text, so capital letters, spelling and the space between the words all matter. Extra blank space at the very start or end of the output is ignored.
