Frequently asked questions

What is Rocket Typing coding practice?

It is a free set of programming problems where you also train your typing speed. For every problem you can type a reference solution in With Code mode, or write your own in Without Code mode, while WPM, accuracy and consistency are measured live.

Which programming languages are supported?

Every problem has reference solutions in 13 languages — Python, JavaScript, Java, C, C++, TypeScript, Go, Rust, Kotlin, Swift, PHP, C# and Ruby. Pick the language in the editor toolbar; Without Code mode lets you write your own solution in any of them.

Do I need an account?

No. Your progress, notes, bookmarks and saved code are stored in your own browser, so you can start solving straight away.

How are my solutions checked?

Run tests your code against the sample cases and Submit judges it against sample plus hidden test cases, all inside your browser.

How does this improve my typing?

Code is full of brackets, quotes and indentation. Typing real solutions repeatedly builds accuracy on the symbols normal typing tests skip, and the result screen shows your WPM, accuracy, consistency and keystroke timeline.
