#5 Find the Length of a String

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a string. Find and print the total number of characters it contains, including letters, digits, spaces, and any other printable characters.

This value is called the length of the string.

Input Format

A single string on one line.

Output Format

Print a single integer — the number of characters in the string.

Constraints

• The string length is between 1 and 200 characters.
• The string may include letters, digits, and spaces.

Sample Input

Hello

Sample Output

5

Explanation

The string Hello contains 5 characters: H, e, l, l, o.
In Python, use the built-in `len()` function: `print(len(s))`.

About this problem: Find the Length of a String

The length of a string is the number of characters it contains — letters, digits, spaces and symbols all count. Every language has a built-in way to get it, from len() in Python to strlen() in C.

Read one line of input and print its length. Python also shows how to count with a loop and with sum(), so you can see what the built-in does behind the scenes.

Find the Length of a String in Python — 3 solutions

len()

s = input()
print(len(s))
  1. Reads a string from input and stores it as s.
  2. Prints the number of characters in s.

Manual counter loop

s = input()
count = 0
for ch in s:
    count = count + 1
print(count)
  1. Reads a string from input and stores it as s.
  2. Starts a counter at 0.
  3. Loops over every character in s…
  4. …adding 1 to the counter for each one.
  5. Prints the final count — the total number of characters.

sum() over a generator

s = input()
print(sum(1 for ch in s))
  1. Reads a string from input and stores it as s.
  2. Adds 1 for every character in s and sums them all — an indirect way of counting the length.

Frequently asked questions

How do you find the length of a string in Python, Java and C?

Python: len(s). Java: s.length(). C: strlen(s) from <string.h>. C++: s.length() or s.size(). JavaScript and TypeScript: s.length. Ruby: s.length. Swift: s.count. PHP: strlen($s). C#: s.Length.

Does the length include spaces?

Yes. Every character is counted, including spaces, punctuation and digits, so "Hi there" has length 8.

Does len() in Go and Rust count characters or bytes?

Both count bytes. For plain English text that is the same as the number of characters, but accented letters or emoji use more than one byte each.
