#19 Prime Numbers Up To N

Medium ⏱ 1 sec 💾 256 MB 🏷 Math

Problem Statement

You are given an integer n. Print all the prime numbers from 2 up to and including n, separated by a single space. If there are none, print an empty line.

Input Format

A single integer n.

Output Format

Print all primes from 2 to n (inclusive), separated by single spaces, on one line.

Constraints

• 1 ≤ n ≤ 100

Sample Input

10

Sample Output

2 3 5 7

Explanation

Among the numbers from 2 to 10, only 2, 3, 5, and 7 have no divisors other than 1 and themselves, so they are printed.
For each number, check whether any smaller number (other than 1) divides it evenly.

About this problem: Prime Numbers Up To N

Finding primes is a classic first algorithm problem — it combines a loop over every candidate number with, for each one, a second loop checking whether anything smaller evenly divides it.

This page's Python solutions show three levels of the same idea: plain nested-loop trial division, a square-root-bounded optimization, and the Sieve of Eratosthenes. Every other language below uses the same straightforward trial-division approach. Solutions in all 13 languages are shown, plus those three Python variations.

Square-root optimisation

import math
n = int(input())
primes = []
for num in range(2, n + 1):
    is_prime = True
    i = 2
    while i <= math.sqrt(num):
        if num % i == 0:
            is_prime = False
        i += 1
    if is_prime:
        primes.append(num)
print(" ".join(str(p) for p in primes))

Sieve of Eratosthenes

n = int(input())
sieve = []
i = 0
while i <= n:
    sieve.append(True)
    i += 1
if n >= 0:
    sieve[0] = False
if n >= 1:
    sieve[1] = False
for i in range(2, n + 1):
    if sieve[i]:
        j = i * i
        while j <= n:
            sieve[j] = False
            j += i
primes = [i for i in range(2, n + 1) if sieve[i]]
print(" ".join(str(p) for p in primes))
  1. Reads n from input and converts it to an integer.
  2. Builds a list of True values, one for every number from 0 to n.
  3. Marks 0 as not prime.
  4. Marks 1 as not prime.
  5. For every number starting from 2 that's still marked prime…
  6. …starts crossing off its multiples, beginning at its square.
  7. Keeps marking each multiple as not prime until past n.
  8. Collects every index still marked prime into a list.
  9. Joins all the primes found with spaces and prints them.

Prime Numbers Up To N in Java — 1 solution

Nested loop trial division

import java.util.Scanner;
import java.util.ArrayList;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());
        ArrayList<Integer> primes = new ArrayList<>();
        for (int num = 2; num <= n; num++) {
            boolean isPrime = true;
            for (int i = 2; i < num; i++) {
                if (num % i == 0) isPrime = false;
            }
            if (isPrime) primes.add(num);
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < primes.size(); i++) {
            if (i > 0) sb.append(" ");
            sb.append(primes.get(i));
        }
        System.out.println(sb.toString());
    }
}

  2. Loops over every number from 2 to n, checking smaller numbers as divisors.
  3. Collects the numbers that stay marked prime into a list.
  4. Builds and prints a space-separated string from that list.

Frequently Asked Questions

What is the simplest way to check if a number is prime?

Test every integer from 2 up to (but not including) the number itself as a possible divisor. If none of them divide it evenly, it's prime.

Why does n = 1 print nothing?

By definition, prime numbers start at 2 — 1 has no numbers to check against and isn't considered prime, so the loop from 2 to n never runs and the output is an empty line.

Is there a faster way to check for primes than this?

Yes — you only need to check divisors up to the square root of the number, since any larger factor would already have a matching smaller one. The Sieve of Eratosthenes is faster still when you need ALL primes up to n at once.
