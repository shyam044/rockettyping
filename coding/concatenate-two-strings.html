#3 Concatenate Two Strings

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given two words. Join them together into a single sentence with exactly one space between them, and print the result.

This operation is called string concatenation — combining two or more strings into one.

Input Format

Two strings are given on two separate lines.
• First line: the first word
• Second line: the second word

Output Format

Print the two words joined by a single space on one line.

Constraints

• Each string contains only printable characters.
• Each string has a length between 1 and 50 characters.

Sample Input

Hello World

Sample Output

Hello World

Explanation

The two inputs Hello and World are combined with a space in between: Hello World.
In Python, you can join strings with the `+` operator or use an f-string: `f"{a} {b}"`.

About this problem: Concatenate Two Strings

String concatenation — combining two or more strings into one — is one of the most common operations in programming. Here you read two words, one per line, and print them joined by exactly one space.

Solutions are shown in 13 languages. In Python there are five approaches: the + operator, str.join(), f-strings, %-formatting and str.format().

Frequently asked questions

How do you concatenate two strings in Python, Java and JavaScript?

All three use the + operator: a + " " + b. C#, Kotlin, Swift, Go and Ruby work the same way. PHP uses the dot operator (.), Rust uses format!, and C has no string + operator so the words are printed together with printf("%s %s").

Why do I need to add the space myself?

Concatenation joins the strings exactly as they are. To get "Hello World" from "Hello" and "World" you must insert the " " between them.

Why do I get a TypeError when adding a string and a number in Python?

Python does not convert types automatically with +. Convert the number with str() first, or use an f-string, which formats values for you.
