#4 Repeat a Word N Times

Easy ⏱ 1 sec 💾 256 MB 🏷 Strings

Problem Statement

You are given a word and a number n. Print the word exactly n times, each occurrence separated by a single space, all on one line.

Input Format

• First line: a string (the word to repeat)
• Second line: an integer n (the number of times to repeat it)

Output Format

Print the word n times on a single line, separated by spaces.

Constraints

• 1 ≤ n ≤ 20
• The word contains only printable characters.
• The word length is between 1 and 30 characters.

Sample Input

Hello 4

Sample Output

Hello Hello Hello Hello

Explanation

The word Hello repeated 4 times, each separated by a space.
In Python, you can use string repetition: `(word + " ") * n`, then strip the trailing space. Or use `" ".join([word] * n)`.

About this problem: Repeat a Word N Times

Given a word and a number n, print the word n times on one line with a single space between the copies. It combines reading input, converting a number, looping or repeating, and building the output without a trailing space.

Python offers four approaches (list repetition with join(), print(*list), a loop and a generator), while Java, C, C++, Go and C# use a for loop and the other languages use built-in repeat helpers.

Frequently asked questions

How do you repeat a string n times in Python?

Multiply it: "ab" * 3 gives "ababab". For a word repeated with spaces in between, multiply a list instead — [word] * n — and join it with " ".join(...).

How do you print a word n times with spaces in Java or C++?

Use a for loop from 0 to n-1 and print a space before every copy except the first (if i > 0). This avoids a trailing space at the end of the line.

Why use join() instead of a loop with +?

join() builds the final string in one pass and never leaves a trailing space, which would make the output differ from the expected line.
